# SupplyWise AI

### E-Commerce Delivery Analytics & Predictive Insights

SupplyWise AI is a portfolio project focused on understanding e-commerce delivery performance, identifying operational issues, and exploring how data analytics and machine learning can support better business decisions.

## Business Problem

Late deliveries and inconsistent order fulfilment can affect customer satisfaction and business performance. This project will analyse historical e-commerce order data to identify delivery patterns, assess seller performance, and investigate factors associated with delays.

## Project Objectives

- Clean, validate, and explore historical e-commerce data using Python.
- Analyse delivery performance and business KPIs using SQL.
- Build an interactive Power BI dashboard.
- Communicate findings through clear visualisations and business recommendations.
- Explore a machine learning model for predicting delivery-delay risk, if feasible.

## Dataset

The project plans to use the public Brazilian E-Commerce Dataset by Olist, containing historical marketplace order information.

Dataset suitability, quality, and usage conditions will be reviewed before analysis.

## Planned Technologies

- Python and Pandas
- SQL
- Power BI
- Scikit-learn
- Git and GitHub
- Microsoft Azure (optional cloud demonstration)
